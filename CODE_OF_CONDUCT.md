# Código de conducta

Queremos un espacio respetuoso para todas las personas que participan en Acta.

**Esperamos:** trato amable y profesional, críticas constructivas sobre el trabajo (no sobre las personas), y paciencia con quien está empezando.

**No toleramos:** acoso, insultos, discriminación, publicar datos personales de otras personas, ni el uso de Acta para espiar o grabar a alguien sin respetar la ley.

Las personas responsables del proyecto pueden editar o eliminar comentarios, issues y contribuciones que incumplan estas normas, y expulsar temporalmente o de forma permanente a quien lo haga. Para avisar de una conducta inadecuada, escribe en privado a quien administra el repositorio o usa el aviso privado de GitHub.

Este código se inspira en el [Contributor Covenant](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).
